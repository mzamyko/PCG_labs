Алгоритм Время (мс) Пикселей

Виртуальный растр

Двумерный массив для хранения пикселей. Алгоритмы работают только с ним, не обращаясь к графике.

col = x − minX
row = y − minY
screenY = (height − 1 − row) × cell

Пошаговый алгоритм

Вычисляет y по уравнению прямой y = y₀ + k(x − x₀) на каждом шаге.

k = Δy / Δx
x = x₀ + i
y = round(y₀ + k × i)

Алгоритм ЦДА (DDA)

Использует приращения координат. Требует вещественных вычислений.

L = max(|Δx|, |Δy|)
dx = Δx / L
dy = Δy / L
x = x + dx, y = y + dy

Алгоритм Брезенхема

Целочисленный алгоритм с переменной ошибки. Работает быстрее за счёт отсутствия вещественных операций.

d = 2×minor − major
if d < 0: d += 2×minor
else: d += 2×(minor−major), y++

Алгоритм Ву (сглаживание)

Вычисляет интенсивность пикселей на основе дробной части координаты для сглаживания линии.

f = y − floor(y)
α₁ = 1 − f
α₂ = f
pixel₁ = α₁, pixel₂ = α₂

Алгоритм Кастла-Питвея

Использует код Ротштейна (последовательность S и D) для построения отрезка.

S — шаг по главной оси
D — диагональный шаг
Код формируется через алгоритм Евклида

Окружность Брезенхема

Строит 1/8 окружности и отражает точки симметрично (8 точек).

d = 3 − 2×r
if d < 0: d += 4×x + 6
else: d += 4×(x−y) + 10, y--

8 октантов

Алгоритм Брезенхема корректно работает во всех направлениях благодаря выбору ведущей оси и знаков приращений.
