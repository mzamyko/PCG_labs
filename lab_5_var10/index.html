Сазерленд–Коэн часть 1 · явное уравнение

      
Отсечение отрезков прямоугольным окном. Вариант 10 требует искать пересечения через Ax + By + C = 0, а не через y = kx + b.

      
Коды областей (outcodes)

      
Каждому концу отрезка присваивается 4-битный код: бит 1 — левее, бит 2 — правее, бит 4 — ниже, бит 8 — выше окна.

      

        
1001слева-сверху
1000сверху
1010справа-сверху

        
0001слева
0000окно
0010справа

        
0101слева-снизу
0100снизу
0110справа-снизу

      

      
Шаги алгоритма

      
    
        
  1. Если код₁ | код₂ = 0 — отрезок целиком видим, принять.
    2. 
        
  2. Если код₁ & код₂ ≠ 0 — оба конца по одну сторону окна, тривиально отбросить.
    3. 
        
  3. Иначе взять конец с ненулевым кодом и построить прямую отрезка:
    4. 
      

      
A = y₂ − y₁,  B = x₁ − x₂,  C = x₂y₁ − x₁y₂

      
    
        
  1. Пересечение с выбранной границей: для y = Y → x = −(B·Y + C)/A; для x = X → y = −(A·X + C)/B.
    2. 
        
  2. Заменить конец точкой пересечения, пересчитать его код и повторить.
    3. 
      

      
Псевдокод

      
// коды: 1-лево 2-право 4-низ 8-верх
пока истина:
  если (c1 | c2) == 0 → принять
  если (c1 & c2) != 0 → отбросить
  c = c1 != 0 ? c1 : c2
  A = y2−y1; B = x1−x2; C = x2·y1−x1·y2
  если c & 8: x = −(B·ymax+C)/A; y = ymax
  иначе если c & 4: x = −(B·ymin+C)/A; y = ymin
  иначе если c & 2: y = −(A·xmax+C)/B; x = xmax
  иначе:          y = −(A·xmin+C)/B; x = xmin
  заменить конец с кодом c, пересчитать код

      
Сложность: не более 4 отсечений на отрезок. Деление ровно одно на каждое пересечение. Вертикальные и горизонтальные отрезки безопасны: при A = 0 или B = 0 соответствующая граница никогда не выбирается (тривиальное отклонение срабатывает раньше).

    


    

      
Кирус–Бек часть 2 · выпуклый отсекатель

      
Отсечение отрезков выпуклым многоугольником через параметрическое задание отрезка и внутренние нормали рёбер.

      
      
Идея

      
P(t) = P₁ + t·D,  D = P₂ − P₁,  t ∈ [0; 1]

      
Выпуклый многоугольник — пересечение полуплоскостей рёбер. Для ребра с точкой Aᵢ и внутренней нормалью nᵢ точка внутри, когда nᵢ·(P − Aᵢ) ≥ 0. Подставляя P(t):

      
tᵢ = −nᵢ·(P₁ − Aᵢ) / (nᵢ·D)

      

        
nᵢ·D > 0пересечение входящее: tE = max(tE, tᵢ)

        
nᵢ·D < 0пересечение выходящее: tL = min(tL, tᵢ)

        
nᵢ·D = 0отрезок параллелен ребру: если снаружи полуплоскости — отбросить

      

      
Видимая часть существует при tE ≤ tL; её концы — P(tE) и P(tL). Начальные значения: tE = 0, tL = 1.

      
Псевдокод

      
tE = 0; tL = 1; D = P2 − P1
для каждого ребра (Aᵢ, nᵢ):  // nᵢ — внутрь
  w = P1 − Aᵢ
  den = nᵢ·D;  num = nᵢ·w
  если den == 0:
    если num < 0 → отбросить; иначе дальше
  t = −num / den
  если den > 0: tE = max(tE, t)   // вход
  иначе:        tL = min(tL, t)   // выход
  если tE > tL → отбросить
вернуть P(tE) → P(tL)

      
Ориентация: знак площади (формула шнурования) задаёт, куда «вывернуть» нормаль (−Eᵧ, Eₓ), чтобы она смотрела внутрь, — поэтому обход по и против часовой стрелки равноправны. Сложность: O(k) на отрезок, k — число рёбер; ровно одно деление на непараллельное ребро.

Что спросят на защите

    

      
Почему явное уравнение, а не y = kx + b?
У формы y = kx + b вертикальный отрезок даёт бесконечный k — особый случай. В Ax + By + C = 0 вертикаль — это просто B = 0, и пересечение с вертикальной границей в этом случае не выбирается: код обоих концов одинаков по X, срабатывает тривиальное отклонение.

      
Когда Кирус–Бек неприменим?
Когда отсекатель невыпуклый: его нельзя представить пересечением полуплоскостей рёбер, и интервал [tE, tL] перестаёт описывать видимую часть. Поэтому приложение проверяет выпуклость знаками векторных произведений соседних рёбер.

      
Какой метод дешевле?
Сазерленд–Коэн выигрывает на тривиальных случаях (только сравнения и битовые операции) и тратит 3 умножения + 1 деление на каждое пересечение. Кирус–Бек тратит ~4 умножения на ребро + 1 деление, зато сразу даёт параметрический интервал и работает с любым выпуклым контуром. Счётчики и бенчмарк это подтверждают численно.
